# 专有名称审计

## 为什么要单独审计

机器翻译和人工润色都容易把语义透明的专名误当普通短语。例如动物名、常见动词或形容词可能实际是机器人平台、模型或任务标签。反方向也有风险：把普通语义词误判为品牌并全局改回英文。正确做法是从官方英文建立证据驱动的术语表，再逐个上下文确认。

Panda、Meta-World、Octo、Diffusion Policy、Pick-Place、Bidir、LIBERO-Spatial 只用于说明风险类型：普通词形专名、带连字符 benchmark、组合模型名、任务标签和平台名。不得将它们当作封闭词表或无条件替换规则。

## 覆盖类别

至少检查：

- 数据集与数据集合并版本；
- benchmark、任务套件、challenge 和 split；
- 模型、方法、基线、policy 和架构；
- 机器人、机械臂、传感器及硬件平台；
- 仿真环境、场景、地图和 world；
- 代码仓库、组织名、包名、命令、URL path 和 handle；
- 指标缩写、坐标轴标签、图例标签；
- 类别标签、动作标签、任务名称和 split 名；
- 缩写、版本后缀、大小写及连字符具有区分作用的名称。

## 从官方英文抽取候选

扫描标题、摘要、正文、heading、table、caption、footnote、appendix、算法和参考链接。组合以下信号，而不是依赖单一正则：

1. 大写开头或内部驼峰、全大写缩写、数字后缀。
2. 连字符或斜杠连接且在多个位置稳定复现。
3. 被 dataset、benchmark、suite、model、policy、robot、arm、simulator、environment、repository、metric、class、task 等类型词修饰。
4. 位于代码字体、链接文本、图例、表头或标签位置。
5. 在官方项目页、代码仓库或论文定义句中作为命名实体出现。
6. 同一字符串的大小写、空格和连字符变体。

给每个候选记录：

| 字段 | 内容 |
|---|---|
| `original` | 官方英文原形 |
| `canonical` | 最终保留形式 |
| `category` | 数据集/模型/平台/标签等 |
| `evidence` | 官方原文片段与位置 |
| `locations` | 正文、table、caption、footnote、appendix 出现位置 |
| `decision` | 保留/翻译/首次双语/排除 |
| `notes` | 大小写、连字符、复数或版本规则 |

## 在中文候选稿中生成风险候选

使用启发式只生成“待核对项”，不能自动修复：

### 回译异常

- 中文词回译后恰好对应官方英文中的高频大写词，但当前中文像普通名词。
- 相同官方词在候选稿中出现多个不一致译法。
- 模型或数据集在正文保留英文，却在 caption、表格或附录中被翻译。

### 位置异常

- 普通中文名词出现在“在 X 上评测”“使用 X 机器人”“来自 X suite”“X-Small/X-Large”等命名槽位。
- 表头、图例、类别标签或代码样式位置出现长中文释义，而官方是短标签。
- 大写、连字符、数字后缀或版本号在中文稿中消失。

### 形态异常

- 同一名称被拆分、合并或替换连字符。
- repository handle、包名或路径被翻译。
- 指标标签被扩写为解释句，导致图表与正文不一致。

## 逐一确认流程

对每个候选：

1. 在官方英文中定位完全匹配和形态变体。
2. 阅读定义句及至少一个使用上下文，确认它是专名还是普通语义。
3. 检查官方项目页或仓库仅用于消歧；论文官方源仍是当前文稿的术语基准。
4. 决定 canonical 形式及首次出现规则。
5. 搜索候选 HTML 的所有文本区域，包括隐藏脚注、caption、table 和 appendix。
6. 仅修复确认的实例。若同形词兼有普通含义，按上下文逐项修改，禁止全局替换。
7. 修复后再次扫描遗漏和误伤。

## 防误改规则

- “普通中文看起来奇怪”不是充分证据。
- 大写单词也可能只是句首词；必须结合类型位置和定义上下文。
- 同一个英文词在不同段落可能分别是专名和普通词。
- 不把参考文献标题中的普通词强制替换成当前论文的专名。
- 不因术语表包含某词就修改公式、代码或 URL 字节。
- 不用回译模型的判断直接覆盖文本；回译只用于召回候选。

## 审计摘要

交付时报告：

- 官方源候选总数与分类分布；
- 确认保留、首次双语、允许翻译和排除的数量；
- 实际修复实例数及涉及的 HTML 区域；
- 人工排除的高风险候选及理由；
- 未决歧义和需要用户决定的命名方式。

代表性变更至少给出“官方原文—错误形式—修复形式—位置—证据”，但不要用几个示例代替全文扫描。
