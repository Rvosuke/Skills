# 验收清单

把本清单作为交付门禁。任何标为“阻断”的项目失败时，不得声明最终完成。

## A. 输入与版本

- [ ] 官方 HTML 已优先使用，或已记录改用官方 TeX/PDF 的原因。
- [ ] 论文标识、版本、URL、获取日期和输入 hash 已记录。
- [ ] baseline 是只读副本。
- [ ] candidate 使用新版本文件名，未覆盖上一版。（阻断）
- [ ] 任务模式与允许变化白名单已明确。

## B. 内容完整性

- [ ] 标题、作者、机构和摘要存在。
- [ ] 章节与小节完整，顺序与官方源一致。
- [ ] 公式/MathML 及公式编号完整。（阻断）
- [ ] table、行列、`rowspan`/`colspan` 和数值完整。（阻断）
- [ ] figure、图片和 caption 完整。（阻断）
- [ ] 算法、脚注、附录完整。
- [ ] 参考文献条目和正文引用关系完整。（阻断）
- [ ] 仅删除了白名单中的在线导航、反馈、遥测等非论文内容。

## C. 翻译质量

不适用于“仅排版”模式；该模式应确认可见文本零变化。

- [ ] 中文自然、专业，符合学术语序，不是逐词翻译。
- [ ] 拆并句未改变事实、主客体、条件、否定或结论强度。
- [ ] 数字、单位、变量、比较关系和统计量保持一致。
- [ ] token、embedding 等按领域惯例处理。
- [ ] 表格、caption、算法自然语言、脚注和附录均已覆盖。
- [ ] 参考文献书目信息未被无授权翻译。

## D. 专名审计

- [ ] 已从官方英文先行抽取术语表。
- [ ] 已覆盖正文、table、caption、footnote、appendix。
- [ ] 数据集、benchmark、任务套件、模型、平台、环境、仓库/handle、指标和类别标签已分类。
- [ ] 已运行回译异常、命名槽位和形态异常候选扫描。
- [ ] 每一处修复均有官方原文证据。
- [ ] 同形普通词按上下文保留，未做误伤性全局替换。（阻断）
- [ ] 大小写、空格、连字符和版本后缀一致。

## E. 编号引用（仅用户要求时）

- [ ] 编号映射规则已记录且稳定。
- [ ] 连续编号规范显示为范围，离散编号使用逗号。
- [ ] 每个编号保有到 bibliography 的内部链接边。（阻断）
- [ ] bibliography ID 唯一，所有目标可达。（阻断）
- [ ] 未要求时保留官方 author-year 样式。

## F. 单文件离线性

- [ ] CSS 全部内联，无 `@import` 或外部 stylesheet。（阻断）
- [ ] JavaScript 如有需要已内联，无外部 `src`。（阻断）
- [ ] 字体不依赖网络。
- [ ] 所有渲染所需图片均为 data URI，MIME 与字节匹配。（阻断）
- [ ] CSS `url()`、`srcset` 和媒体资源无网络依赖。
- [ ] 在断网的 `file://` 中可完整显示。（阻断）
- [ ] 未启动 HTTP server 或监听端口。

## G. 结构审计

运行 `scripts/audit_html.py baseline.html candidate.html --json audit.json`，并结合任务模式人工判定。

- [ ] DOM 标签与 ID 差异已分类。
- [ ] 可见文本 diff 符合白名单；仅排版模式必须为空。（阻断）
- [ ] MathML 数量和内容 hash 守恒。（阻断）
- [ ] table 网格、span 和数据差异已核对。（阻断）
- [ ] figure 和图片数量符合预期。
- [ ] data URI 可解码，图片 hash 已记录。（阻断）
- [ ] bibliography、脚注和引文容器完整。
- [ ] citation/link 边未丢失。（阻断）
- [ ] 所有内部 fragment 目标存在。（阻断）
- [ ] 无非授权外部 CSS/JS/字体/图片依赖。（阻断）

脚本输出是证据，不是自动豁免。翻译模式下文本 diff 很大是预期现象，但结构差异仍需解释；排版模式下任何文本差异都要停止交付。

每个格检查：

- [ ] 表格按真实宽度平铺；仅真正溢出的移动宽表局部滚动。
- [ ] 正文、caption、公式、MathML 和图片无裁切。

## I. 交付报告

- [ ] 文件路径与版本列全。
- [ ] 修改摘要区分内容改动、术语修复、引用转换和纯样式。
- [ ] 术语审计摘要包含数量、类别、代表性证据和排除项。
- [ ] 视觉矩阵逐格报告通过/失败/未执行及修复状态。
- [ ] 结构完整性报告覆盖所有审计维度。
- [ ] 已知限制如实列出。
- [ ] 审计 JSON 和必要截图/记录可追溯。

## 最终判定

只有 A–I 的适用阻断项全部通过，才可交付“最终版”。否则交付状态必须写为“草稿”“待视觉验收”或“审计失败”，并明确下一步。
