# 翻译指南

## 目标

译文应像中文学术论文，而不是逐词对齐的双语练习。忠实意味着事实、逻辑、范围和语气等价，并不要求保留英文句法。

## 来源纪律

1. 以官方 HTML 为首选结构基准，因为它通常保留章节、MathML、引用和无障碍语义。
2. 官方 HTML 缺项或转换错误时，用官方 TeX 校核公式、宏、caption 和算法。
3. PDF 用于核对版面、图表位置和前两种来源无法确认的内容，不从 OCR 猜测已有可靠源的文本。
4. 记录论文标识、版本、来源 URL、获取日期及来源间冲突。发生冲突时不要静默选择。

## 翻译单位与顺序

按以下顺序工作，便于先固定高风险词汇：

1. 元数据：标题、作者、机构；作者名默认不翻译，机构采用公认中文名或保留官方英文。
2. 摘要和引言：建立领域语气、缩写和核心术语。
3. 术语表：从全文抽取并确认专名与惯用英文。
4. 正文各节：保持章节层级和段落语义。
5. 表格、figure caption、算法、脚注。
6. 附录及补充材料。
7. 参考文献：通常保留原文书目信息，只转换引文显示时修改链接容器。

不要把表格、caption、脚注和附录当作次要内容；全文翻译必须覆盖这些区域。

## 自然中文规则

- 优先“研究主体—方法—条件—结果”的中文信息顺序，避免长定语链。
- 英文长句可拆成两句；相邻短句可合并，但必须保留因果、转折、条件和限定范围。
- 明确代词指向。必要时重复论文中的主体名称，不凭空补充解释。
- 区分“表明、提示、证明、导致、相关”等证据强度，不把弱结论强化。
- 保留否定、比较级、近似词、置信区间、单位、上下标和数值精度。
- 中文正文使用全角标点；公式、代码、标签、英文缩写内部保持原格式。
- token、embedding、benchmark 等是否保留英文取决于领域惯例；不要为了“中文化”制造陌生译名。
- 缩写首次出现遵循原文。如果提供“中文（English, ABBR）”，确保英文与缩写来自官方源。

## 结构保护

- 只替换文本节点或明确允许的展示容器，不通过重新生成整页破坏 ID 和链接。
- 不改动 MathML、LaTeX annotation、公式编号及引用目标。
- 保留 `<table>` 的单元格顺序、`rowspan`、`colspan`、表头语义与数值。
- 图片 alt 可翻译，但 `src` 嵌入和图片字节不应因翻译改变。
- caption 中的变量、标签、方法名和数据集名按术语表保护。
- 算法中的自然语言注释可翻译；标识符、函数名和伪代码语义不得改变。
- 参考文献书目信息默认保持原文，避免误译论文标题造成检索困难。

## 段级核对

每个单元完成后执行双向核对：

1. **英文到中文**：每个事实、关系、限定和引用是否有对应表达。
2. **中文到英文**：中文中的每个事实是否能在官方英文中定位。
3. **符号核对**：数字、百分比、单位、变量、引用、脚注和公式编号是否一致。
4. **语气核对**：may/can/likely/significantly 等是否被正确表达。
5. **术语核对**：受保护专名是否保持统一，普通词是否未被误判为专名。

## 三种任务模式

### 全文翻译

允许可见文本整体变化，但章节树、公式、表格网格、图片、引用边和 ID 应尽量守恒。若官方结构本身需修复，把结构修复与翻译分开记录。

### 专名误译修复

先从官方英文定位证据，再做最小替换。不要顺便润色邻近段落。建立逐项变更表：中文误译、官方原文、类别、位置、修复形式、确认依据。

### 仅排版

冻结所有可见文本和语义内容。只修改容器、CSS、必要的无障碍属性和低风险交互。任何文字“顺手修正”、空格归一化或引用重排都属于越界，除非用户另行授权。

## 完稿语言检查

- 搜索残留的导航文案、翻译提示词、占位符和未处理正文英文；合理专名和参考文献不算残留。
- 搜索中英标点混乱、连续空格、孤立括号和被拆断的引用。
- 抽样回译高风险段落：摘要、结论、数值密集段、表格 caption、限制与伦理声明。
- 让术语表覆盖正文、table、caption、footnote、appendix 的每个出现位置。
- 不以“读起来顺”替代与官方源逐项对照。
